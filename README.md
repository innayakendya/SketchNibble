# SketchNibble

Simplifies digital painting workflows by providing customizable brushes and color palettes for artists.

With SketchNibble, you get a lightweight tool that stays out of your way.

**What you get**

- Simplifies digital painting workflows by
- providing customizable brushes and color
- palettes for artists

## Key Features

- Simplifies digital painting workflows by
- providing customizable brushes and color
- palettes for artists

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchNibble.git`
2. `cd SketchNibble`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SketchNibble, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
